👩‍🏫 선생님 전용: 코딩 없이 1분 만에 우리반 게시판(Firebase) 연결하기

  1. 여기(Firebase 콘솔)를 눌러 구글 로그인 후 [프로젝트 만들기]를 클릭합니다. (애널리틱스는 끄기)
  2. 왼쪽 메뉴에서 [빌드] ➔ [Realtime Database] 클릭 후 [데이터베이스 만들기]를 누릅니다.
  3. 보안 규칙에서 반드시 [테스트 모드에서 시작]을 선택하고 [사용 설정]을 누릅니다.
  4. 왼쪽 상단 톱니바퀴(프로젝트 설정)를 누르고 아래로 내려가 웹 아이콘(</>)을 눌러 앱을 등록합니다.
  5. 화면에 나오는 const firebaseConfig = { ... }; 코드를 통째로 복사해서 오른쪽 빈칸에 붙여넣고 [자동 연결하기]를 누르면 끝납니다!

💡 연결 후 상단의 [🔗 학생 배포용 링크 복사]를 눌러 학생들에게 전달하면, 학생들 패드에서는 설정 창 없이 바로 우리반 게시판으로 연결됩니다!

🏃‍♂️ 캐릭터에 생명을 불어넣어 볼까요?

  1. 1단계에서 그린 내 캐릭터 그림이 기기에 저장되었는지 확인합니다.
  2. 아래 파란색 [Animated Drawings 열기] 버튼을 눌러 이동합니다.
  3. 사이트에서 [Get Started] ➔ [Upload Photo]를 눌러 내 캐릭터 그림을 올립니다.
  4. 상자 크기를 맞추고, 관절 위치를 콕콕 찍어 맞춥니다.
  5. 마음에 드는 재미있는 동작(춤추기, 점프하기, 걷기 등)을 고릅니다.
  6. 화면의 [Share] 버튼이나 전체화면 버튼을 눌러 완성된 영상(MP4)을 기기에 저장합니다.
